QUEST FOR LIFELONG LEARNERS — COMPLETE ILLUSTRATED GAME

1. Unzip the archive into a folder.
2. Open index.html in Chrome, Safari, Firefox, or Edge. The full game and
   illustrations work offline (fonts may fall back to system fonts).
3. Roll a real d20 to select a learner, optionally reveal one of four
   Cognition Weapons, draft the redesign, then roll again for the Boss Battle.

Contents:
  index.html — working browser game, all approved game-master wording
  images/ — all sixteen original game illustrations
  game_text_master.json — verbatim game-copy data backing the browser game

The Boss Battle d20 is fictional luck, never a score or evaluation of the
participants' assessment redesign. No content is sent over the network.

Source of truth: Quest_for_Lifelong_Learners_GAME_TEXT_MASTER_20261105.txt

Dilemma, two design priorities, four Cognition Weapons, and 20 Boss Battles.
